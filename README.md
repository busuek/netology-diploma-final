## Описание
Инфраструктура для сайта, включающая балансировку нагрузки, мониторинг (Zabbix), сбор логов (Elasticsearch + Kibana + Filebeat) и резервное копирование. Развертывание полностью автоматизировано с помощью **Terraform** и **Ansible**.

## Архитектура
* **Сеть:** VPC с публичной и приватными подсетями в разных зонах доступности.
* **Бастион:** Единственная точка входа по SSH (публичный IP).
* **Веб-серверы (web1, web2):** В приватных подсетях, Nginx, за Application Load Balancer.
* **Мониторинг (Zabbix):** Сервер в публичной сети, агенты на всех ВМ.
* **Логирование:** Elasticsearch и Kibana в Docker (с включенной аутентификацией), Filebeat на веб-серверах.
* **Бэкапы:** Автоматические снапшоты всех дисков (ежедневно, хранение 7 дней).
